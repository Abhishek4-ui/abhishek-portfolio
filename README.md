# Abhishek Kumar — Neon Portfolio

A premium black + neon-green responsive portfolio built with React, Vite and Framer Motion.

## Included

- Premium hero section inspired by the supplied reference
- Your profile photo with background-blended neon treatment
- About section
- Projects: Build AI + Amazon Clone with your actual project screenshots
- GitHub links
- Skills grouped by category
- NPTEL certificate gallery with full-screen preview + download
- Education
- Contact section
- Email-based contact form
- Download CV button
- Dark / light mode
- Responsive mobile navigation
- Scroll animations and hover effects
- Back-to-top button

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build

```bash
npm run build
```

## Important: CV

`public/cv.pdf` is intentionally a placeholder. Replace it with your actual CV PDF. Keep the filename `cv.pdf` and the Download CV button will automatically work.

## Customize

Main content is in:
- `src/data/content.js`

Main UI:
- `src/App.jsx`

Styling:
- `src/styles.css`

Assets:
- `public/assets/`
